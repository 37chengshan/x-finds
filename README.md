# x-finds

刷 X 刷到的好仓库 / 文章 / 项目 / 灵感收藏夹。

- 仪表盘：https://37chengshan.github.io/x-finds/（手机和电脑都能看，侧边栏可以收起）
- 数据源：`data.json`，仪表盘 `index.html` 直接读它渲染，不用构建步骤。

## 怎么存一条

把链接 + 一句“好在哪”发给苏茜，她会按下面格式追加到 `data.json`，然后推送到 GitHub Pages。

```json
{
  "id": "20261104-xxx",
  "title": "标题",
  "url": "https://…",
  "type": "仓库 / 文章 / 项目 / 灵感",
  "tags": ["标签1", "标签2"],
  "date": "2026-11-04",
  "source": "X 刷到",
  "note": "一句话：好在哪",
  "detail": ["可展开的补充要点"]
}
```

`id` 用日期 + 简称，全库唯一。`type` 只能是上面四种之一，侧边栏按它筛选。

## 仪表盘是怎么做的

按这次收藏本身的那套“高定 UI 10 条铁律”做的：

1. 去边框，靠 1%–3% 微明度分层，禁纯黑 #000
2. 输入框聚焦不用 outline，用加深双环 box-shadow 造咬合感
3. 暗色下字重全降 40，防白字发胖
4. 标题流式打字：单字 90ms 从 blur(6px) 到清晰，相邻字错开 30ms
5. 行内图标 vertical-align:-0.125em
6. 数字 tabular-nums 锁等宽
7. 详情折叠用 Grid 0fr→1fr，不用 JS 算高
8. 正文 text-wrap:pretty 防孤字
9. 拖拽用过阻尼弹簧（零回弹咬死），点赞用欠阻尼微弹
10. 复制对勾 2.5s 后自动淡出恢复

点赞和拖拽排序只存在你本地浏览器里，不会改 `data.json`；要永久改顺序或内容，找苏茜改数据源。
